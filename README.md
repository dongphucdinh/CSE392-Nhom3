# ToDoList
# 📝 ToDoList – Task Management Application

Ứng dụng quản lý công việc giúp người dùng dễ dàng tạo, theo dõi và quản lý các nhiệm vụ hằng ngày. Dự án được xây dựng với mục tiêu tối ưu trải nghiệm người dùng, giao diện thân thiện và thao tác đơn giản.

## 🚀 Features

- ➕ **Add Tasks:** Thêm công việc mới.
- ✏️ **Edit Tasks:** Chỉnh sửa nội dung công việc.
- 🗑️ **Delete Tasks:** Xóa công việc không cần thiết.
- ✅ **Complete Tasks:** Đánh dấu công việc đã hoàn thành.
- 📋 **Task Management:** Quản lý danh sách công việc.
- 🔍 **Filter Tasks:** Lọc công việc theo trạng thái.
- 💾 **Data Storage:** Lưu trữ dữ liệu công việc.

## ⚙️ Installation & Setup

**1. Clone repository**

```bash
git clone https://github.com/your-username/ToDoList.git
```

**2. Navigate to project directory**

```bash
cd ToDoList
```

**3. Run the application**

Mở file `index.html` bằng trình duyệt hoặc sử dụng VS Code Live Server.
